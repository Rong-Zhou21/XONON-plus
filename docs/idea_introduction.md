# Idea 简介:面向 Minecraft 开放世界长序任务的案例库决策器与可调度技能库

> 一段话介绍(含任务背景、涉及领域、相关技术路线、创新点)

我做的是面向 Minecraft 开放世界(open-world,开放世界)长序任务(long-horizon task,长程任务)的**具身智能体(embodied agent,具身智能体)规划与执行**——智能体在第一人称视觉输入下,需要把"合成钻石镐""制作金胸甲"这类动辄几十上百步、且跨多级物品依赖的目标,自动分解成可执行子目标并依次完成。该工作处于**具身智能 / 大模型智能体(LLM agent,大模型智能体)/ Minecraft 智能体**的交叉领域,技术路线沿袭 Optimus-1、XENON(ICLR 2026)一脉:用视觉语言大模型(VLM,视觉语言模型;这里是 Qwen2.5-VL-7B)做知识引导的**任务规划器**,用 STEVE-1 等**低层控制器(controller,底层控制器)**执行子目标,并以经验记忆库辅助知识纠错。我的创新点有两个:其一是**"案例库 + 决策器"**——把每次决策的状态快照、候选动作与成败结果沉淀为结构化案例库,并训练一个**检索增强的决策打分器(RADS,Retrieval-Augmented Decision Scorer)**,高置信时直接复用历史经验、低置信时弃权(abstain,弃权)回退到规划器,从而在不降低成功率的前提下减少大模型调用、提升对长尾与分布外情形的泛化;其二是**"可被决策器调用的技能库"**——把环境感知与脱困、抬升、拾取等恢复行为封装成可调度、可记录、可评估的 **option 技能(时序抽象 option,时序抽象选项)**,由决策器在硬规则放行的合法候选中进行调度,并用"执行前后的环境状态差分"作为**零推演的进展函数(progress function,进展函数)**在线评判每个技能是否真正有效——相当于把过程奖励模型(PAV)中"步骤进展即价值"的思想,在状态可观测的具身环境里落地为一种确定性、零成本的度量,从而把原本散落的硬规则恢复逻辑升级为可学习、可消融的统一技能调度问题。
